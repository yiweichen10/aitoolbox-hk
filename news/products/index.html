Claude Code Launches Experimental Code Mode

Claude Code's new Code Mode has the model write JavaScript to complete multi-step tool calls in one pass, supporting parallel execution and output filtering. The experimental feature is off by default; early tests report 22-23% lower bills and up to 77% token reduction.

WhyThe savings come not from a smarter model but from fixing who organizes the tool loop: tool definitions re-sent every turn dropped from 16 to 3, and intermediate outputs no longer enter the context window. The trade-off is supervision granularity - in Auto mode the classifier only reviews the whole code block and never sees runtime values, so scheduling power moves down to the model while oversight gets coarser.

Browser Use 1.0: 24 Tools Consolidated Into One

Browser Use 1.0 replaces 24 discrete action tools with a single Python REPL plus CDP. Same-model benchmark scores rose 14-33 points while costs fell to between 1/2.7 and 1/5.2 of previous levels.

WhySwapping tool menus for code primitives is becoming consensus in agent design, and the maintenance burden of 24 specialized tools disappears with it. Teams doing browser automation and scraping face a prompt-and-toolchain rewrite to migrate to 1.0, but the capability ceiling is clearly higher - CAPTCHA-class challenges still need dedicated tools as backstops.

Runway's Software Factory: Agents Now Land 38% of Merged PRs

Runway reports agents drove 38% of merged PRs in October - up from 0.1% in June - with monthly merges going from 2 to over 3,000, and first-approval wait times down from 2.3 hours to 5 minutes.

WhyRead the rollback-rate comparison carefully: AI approvals concentrate on low-risk changes, and on a like-for-like basis the article's own numbers show parity - the raw 0.10% vs 0.5% overstates the advantage. The engineering takeaway is moving from per-change human gatekeeping to risk-tiered gates: database migrations, secrets and auth stay human-locked. Their staged handover write-up is a copyable template for metrics and delegation order.

OpenHands Hands CVE Remediation to an Agent Pipeline

October set a record with 17,000 new CVEs. OpenHands now routes most fixes through agents: mirrors cut fixable criticals from 87 to 5 and highs from 1,997 to 188.

WhyCVEs are a smart pilot for agent handover: results are verifiable (vulnerability counts drop and nothing breaks), and remediation steps are standardized - exactly the work shape agents absorb best. October's roughly 550 new CVEs per month already exceed human capacity. The workflow is open-sourced with Teams and reusable; major version upgrades and vulnerability-validity judgments still need humans.

Perplexity Brain Writes Its Own Personal Skills

The Perplexity Brain agent automatically writes and updates personal skills from conversation history. In an 8-week randomized test, 72.9% of users gained new skills and tool-call failures dropped 11% at unchanged cost.

WhySkills are memory externalized without weight changes: Brain finds repeated patterns in conversation traces, only writes when evidence is sufficient, caps 10 skills per user, and shared-skill changes require replay tests plus human approval. An 8-week controlled trial showing an 11% failure-rate drop at flat cost is the first quantified evidence for the 'gets better the more you use it' claim.

Google Opens Genie 4 World Model API

Google opened Genie 4 to developers: text- or image-generated interactive 720p 24fps worlds with 48kHz stereo audio and keyboard control, at about $6.05/minute with 120-second session limits.

WhyA world model with public pricing means developers can finally do the math: $0.1/second fits prototyping, spatial-concept visualization and robot-simulation training. Don't expect persistent worlds - there's a rolling window with no 3D scene graph, sessions are disposable, and billing continues after you close the tab until you explicitly call complete() or cancel().
