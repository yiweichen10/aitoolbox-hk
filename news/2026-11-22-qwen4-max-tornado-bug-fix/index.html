Qwen4 Max Fixes a Tornado Framework Bug in a Single Call

Alibaba's flagship model landed on the Together inference platform with 1M context. Loading the entire Tornado repository - 650K tokens across 344 files - it produced a passing patch in 72 seconds for $0.69.

Why it matters

The demo matters because of the 'zero retrieval' part: with the full 344 files in context, the model located the bug on its own and cited a prior iostream precedent the report hadn't mentioned - the same one the maintainer's fix referenced. This is the first demonstration that whole-repo repair via 1M context is viable, and with cache replay down to about 3 cents, the commercial math for long context finally closes.
