OpenAI Ships GPT-Live-1.1 Voice Model on the API

The full-duplex voice model defaults to 128K context and is exclusive to OpenAI's cloud. A new standby idle billing mode costs $0.02/minute - 60% below the active rate of $0.05.

WhyThe real cost driver for voice agents is idle waiting, and standby pricing at 40% of the active rate meaningfully reshapes the bill structure for always-on outbound-call businesses. But the 1.1 accent and transcription improvements are all self-reported with zero benchmark scores, and deep reasoning is outsourced to a separately-billed backend text model - the voice layer got cheaper, but the total bill may not follow.

Qwen4 Max Fixes a Tornado Framework Bug in a Single Call

Alibaba's flagship model landed on the Together inference platform with 1M context. Loading the entire Tornado repository - 650K tokens across 344 files - it produced a passing patch in 72 seconds for $0.69.

WhyThe demo matters because of the 'zero retrieval' part: with the full 344 files in context, the model located the bug on its own and cited a prior iostream precedent the report hadn't mentioned - the same one the maintainer's fix referenced. This is the first demonstration that whole-repo repair via 1M context is viable, and with cache replay down to about 3 cents, the commercial math for long context finally closes.

Thinking Machines Lab Releases Laptop-Runnable Inkling 2 Mini

A recurrent transformer whose middle 12 layers run 3 times per token. MoE total parameters 26.4B with 3.4B active, around 20GB - it runs on a 32GB Mac.

WhyThe recurrent architecture hides serial depth inside layer loops, so reasoning no longer has to be written out fully in chain-of-thought - which turns CoT monitorability into a fresh research question, exactly why TML open-sourced it alongside the variable-loop variants. Native NVFP4 quantization and the 20GB footprint pull the lightweight-model competition down to consumer hardware.
