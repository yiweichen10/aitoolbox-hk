Claude Code Launches Experimental Code Mode

Claude Code's new Code Mode has the model write JavaScript to complete multi-step tool calls in one pass, supporting parallel execution and output filtering. The experimental feature is off by default; early tests report 22-23% lower bills and up to 77% token reduction.

WhyThe savings come not from a smarter model but from fixing who organizes the tool loop: tool definitions re-sent every turn dropped from 16 to 3, and intermediate outputs no longer enter the context window. The trade-off is supervision granularity - in Auto mode the classifier only reviews the whole code block and never sees runtime values, so scheduling power moves down to the model while oversight gets coarser.

Anthropic Mathematician Claims Claude Proof of the Riemann Hypothesis

Mathematician Alpöge says the claimed proof also covers the generalized Riemann hypothesis, published as 14 Lean packages spanning over 250,000 printed pages. Hours later, Stanford released a competing human-only draft by mathematician Masullo.

WhyLean formalization makes a quarter-million-page proof machine-checkable line by line for the first time - but whether the problem statement was correctly translated into code still relies on expert spot-checks, and that will remain the long-running controversy around AI mathematical proofs. Meanwhile, the human draft had its questionable points found by other AI-assisted reviewers within eight hours. The two routes checking each other is more notable than who proved it first.

OpenAI Ships GPT-Live-1.1 Voice Model on the API

The full-duplex voice model defaults to 128K context and is exclusive to OpenAI's cloud. A new standby idle billing mode costs $0.02/minute - 60% below the active rate of $0.05.

WhyThe real cost driver for voice agents is idle waiting, and standby pricing at 40% of the active rate meaningfully reshapes the bill structure for always-on outbound-call businesses. But the 1.1 accent and transcription improvements are all self-reported with zero benchmark scores, and deep reasoning is outsourced to a separately-billed backend text model - the voice layer got cheaper, but the total bill may not follow.

Qwen4 Max Fixes a Tornado Framework Bug in a Single Call

Alibaba's flagship model landed on the Together inference platform with 1M context. Loading the entire Tornado repository - 650K tokens across 344 files - it produced a passing patch in 72 seconds for $0.69.

WhyThe demo matters because of the 'zero retrieval' part: with the full 344 files in context, the model located the bug on its own and cited a prior iostream precedent the report hadn't mentioned - the same one the maintainer's fix referenced. This is the first demonstration that whole-repo repair via 1M context is viable, and with cache replay down to about 3 cents, the commercial math for long context finally closes.

Nasdaq 100 Suffers Worst Week Since the Pandemic: Down 10.4%

The Nasdaq 100 fell 5.6% on Friday, closing the week down 10.4% - a 20% retreat from October highs that puts the index in bear-market territory. Nvidia plummeted 14% on Friday amid reported SEC scrutiny of its accounting practices.

WhyDoubts about massive AI infrastructure spending, reports of an SEC probe into Nvidia over undisclosed China sales, and post-election political headwinds combined into a perfect storm for AI stocks. For practitioners, this is the first time the market has collectively demanded proof of the demand narrative that capex has been funding - and both financing windows and valuation stories are tightening at the same time.
