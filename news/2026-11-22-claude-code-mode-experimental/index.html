Claude Code Launches Experimental Code Mode

Claude Code's new Code Mode has the model write JavaScript to complete multi-step tool calls in one pass, supporting parallel execution and output filtering. The experimental feature is off by default; early tests report 22-23% lower bills and up to 77% token reduction.

Why it matters

The savings come not from a smarter model but from fixing who organizes the tool loop: tool definitions re-sent every turn dropped from 16 to 3, and intermediate outputs no longer enter the context window. The trade-off is supervision granularity - in Auto mode the classifier only reviews the whole code block and never sees runtime values, so scheduling power moves down to the model while oversight gets coarser.
