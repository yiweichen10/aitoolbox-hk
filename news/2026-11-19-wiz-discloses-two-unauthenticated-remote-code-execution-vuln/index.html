Wiz discloses two unauthenticated remote code execution vulnerabilities in NGINX

Wiz and other teams disclosed two NGINX HTTP/2 vulnerabilities that allow unauthenticated remote code execution, with a CVSS 4.0 score of 9.2; F5 released fixes on 11-18.

Why it matters

The vulnerabilities are in NGINX itself, so even secure application code cannot stop them; Wiz's testing showed even a purely static site can be compromised, and common mitigations such as ASLR are ineffective. If upgrading is not possible in time, temporarily disabling HTTP/2 can help; CDN/WAF can partially mitigate. NGINX hosts over 225 million websites, so the impact is internet-wide.
