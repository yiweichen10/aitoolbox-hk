### 🔍 FAQ schema 缺失根因（重新定性，推翻上条 P1-2 结论，2026-08-05 21:xx）
- **用户问**：「为什么有些文章还是没有FAQ，是因为没有执行自检吗？」
- **答：不是自检缺失**。生成 prompt 要求写 FAQ，112/120 文章含 FAQ 标记。真正根因在 build 的 **FAQ 区块定位器 bug**：
  - 旧 build 用 `_content_for_faq.upper().find('FAQ')` 找区块起点 → 但文章用的是 **`## Frequently Asked Questions`** 完整拼写，**该字符串 `.upper()` 不含子串 `FAQ`**（实测 `'FAQ' in 'FREQUENTLY ASKED QUESTIONS'.upper()` == False）→ 定位失败 → 后续4种正则策略全部跳过 → 0 提取。
  - 那 32 篇"有 schema"的，恰恰是用 `## FAQ:` 缩写标题（含独立 `FAQ` token），被 `.find('FAQ')` 命中 → 误打误撞成功。
- **治本修复**（遵守"禁止治标"）：`scripts/build_en.py` 4 处区块定位器统一改为 `re.search(r'(?im)^##\s*(frequently\s+asked\s+questions|faq\b)', ...)`，按 heading 精准定位 FAQ 区块。已备份 `build_en.py.20260805-faqfix.bak`，`py_compile` 通过。
- **实测提升**：复刻逻辑跑全库，FAQPage schema 产出 **32 → 104 / 120**（+72 篇纯 build 修复，数据零改动）。
- **残余 16 篇（真·内容层问题，非 build bug，需另补）**：
  - A) 15 篇无 `## FAQ` 标题区块（内容缺口，需补写 FAQ）：ai-tools-for-teachers-2026, ai-tools-for-content-creators-2026, best-ai-tools-for-freelancers-2026, ai-tools-for-social-media-2026, best-ai-chatbots-2026, how-to-use-ai-to-make-money-online-2026, 48-best-ai-tools-roi-benchmark-2026, luma-ai-review, napkin-ai-review, deepseek-v4-review, gemma-4-review-open-source-google-ai-2026, best-ai-tools-for-podcasters-2026, best-ai-tools-for-faceless-youtube-channels-2026, ai-tools-that-make-money-2026, best-free-ai-tools-2026
  - B) 1 篇 `best-ai-tools-for-seo-2026`：有 `## FAQ` 标题但 `### ` 问题行空缺（如 `### \nThere is no single...`）→ 正则要求问题行含 `?` 且非空，格式缺陷，需内容补全
- **结论**：原 P1-2「74%文章没写FAQ」是误判；真实分布=104可自动修复(已修) + 15待补写 + 1格式缺陷。下一步需重建+部署方能线上生效，且对 16 篇做内容补 FAQ（治本，非截断）。
