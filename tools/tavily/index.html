What Tavily Actually Is

Tavily is the web-access layer for AI agents. A search engine shows a human ten blue links; Tavily returns cleaned, LLM-ready content that software can read, cite and reason over. One API key covers five jobs - Search (results tuned for models, at basic or advanced depth), Extract (readable content from URLs you already have), Map (a site's structure), Crawl (map plus extract across a domain) and Research (multi-step investigations that come back as cited reports). Official SDKs ship for Python and JavaScript alongside a CLI and a hosted MCP server, and the integrations list reads like the agent-framework index: LangChain, LlamaIndex, CrewAI, AutoGen, Pydantic AI. The company was acquired by Nebius in 2025, which put real infrastructure money behind what started as a researcher's tool.

For builders, this is infrastructure in the same sense OpenRouter is infrastructure for text models: invisible to end users, and the reason their answers have sources.

The Money Angle

Agent-building services run on it. The most direct path from this API to income is building automation for businesses that need current information: monitoring agents, lead-research pipelines, competitive watch, internal RAG over live sources. Your Tavily cost is cents per task - a monitoring agent checking 20 queries a day at 1-2 credits each burns roughly 600-1,200 credits a month, i.e. inside the free tier or one $30 Project plan - while clients pay hundreds per month for the outcome. For the surrounding stack, see our workflow automation comparison and the agent frameworks guide covering Crew AI and friends.

The free tier is a business plan, not a demo. 1,000 renewing credits per month with no card is enough to prototype, demo to clients, and in some cases run a small production workload forever. Failed extractions cost nothing, and per-endpoint pricing is published - you can quote a per-task cost to a client before you write the code, then set margin on top. That is a healthier starting position than most "AI agency" tool stacks, where the unit economics are guesswork.

Content operations. Research-heavy publishing - comparisons, market summaries, cited newsletters - gets a fact-checking layer that runs for pennies. The honesty caveat: Tavily retrieves what is published; editorial judgment about what is true stays human.

The Honest Cons

The free tier rewards discipline and punishes autonomy: an agent left alone with the Research endpoint can spend a month's credits in a few deep runs, so budget guardrails are your code's job, not the API's. The privacy posture requires a read: Tavily's policy allows portions of query data to improve responses unless you configure otherwise, and queries can be shared with third-party indexes when direct retrieval fails - for client-confidential workloads, that is a contract conversation, not a settings checkbox. There is no self-hosting and no visibility into the proprietary index, so regulated industries will want the Enterprise tier's terms. And it is plumbing: there is no UI to browse, no answer page to show stakeholders - demos still need your own interface in front of it.

Bottom Line

Tavily is the default answer to "how does my agent reach the web" - free enough to build on indefinitely, cheap enough that the API cost never threatens your margin, and integrated with every framework your stack will touch. Its limits are equally clear: mind the privacy terms on client data, cap your research loops in code, and remember that retrieval quality is only as good as the sources behind it. Questions we get asked

Is Tavily actually free?

Yes, on the Researcher plan: 1,000 API credits every month, no credit card, and the same API surface as paid tiers. 1,000 credits is 1,000 basic searches or 500 advanced searches per month. Paid plans start at $30/month for 4,000 credits; pay-as-you-go is $0.008 per credit.

How many credits does one operation cost?

Basic Search: 1 credit. Advanced Search: 2. Extract: 1 credit per 5 successful URLs (failed ones are free). Map: 1 credit per 10 pages. Research: dynamic - a deep research run can cost up to 250 credits, so guard it behind explicit user actions rather than agent autonomy until you have measured your workload.

Tavily or Exa - which should I build on?

Both sell web retrieval for AI systems and both have free tiers. Tavily bundles search, extraction, crawling, mapping and research behind one credit pool with a flat monthly free allowance - the pragmatic pick when you want one integrated workflow. Exa centers on semantic search quality and neural ranking, with a $10/month free credit refresh. Many production stacks run both: semantic discovery on Exa, deterministic retrieval and crawling on Tavily. The full cost math is in our search API pricing comparison.
